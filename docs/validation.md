# Qt/C++ 0.2.0 验证记录

日期：2026-10-15。环境：Windows 11 / Qt 6.8.0 / MSVC 2022 x64；WSLg Arch Linux / Qt 6.11.1 / GCC 16 x64。设备未连接。进程 CPU 归一化依据本机 16 个逻辑处理器。

## 本机构建资源测试

| 场景 | 时长 | RSS 峰值 MB | 私有内存峰值 MB | 空闲 CPU / 单核 % | 空闲 CPU / 整机 % |
|---|---:|---:|---:|---:|---:|
| Windows，七种界面后静置 | 60 秒 | 60.29 | 29.48 | 0.028 | 0.0018 |
| Windows，70 次主题切换 / 70 次图层编辑 | 65 秒 | 60.52 | 32.42 | 0.545 | 0.034 |
| Linux，七种界面后静置 | 60 秒 | 83.72 | 31.29 | 2.322 | 0.145 |
| Linux，72 次主题切换 / 72 次图层编辑 | 65 秒 | 93.02 | 40.51 | 1.980 | 0.124 |

MB 为十进制，RSS 包含共享库常驻页；Windows 使用工作集 / 峰值工作集，Linux 使用 `/proc/self/status` 的 VmRSS / VmHWM；私有内存字段分别来自 PrivateUsage / RssAnon，二者含义不完全相同。CPU 仅计算标记为空闲且启动至少 5 秒后的采样时间；压力阶段的 CPU 不用该空闲指标代表。报告完整采样位于源码目录 `artifacts/*/resources.json`。

这些数据来自真实原生窗口，测试同时操作页面、配色、语言、图层和托盘。测试采样定时器只在命令行测试模式存在。用户任意导入大图、多文档历史或主动选择其他字体后端时占用可能增加；这里验证的是内置主题和基本操作，不构成硬内存上限。

## 最终发布包复测

Windows 清除 Qt 开发环境 PATH，使用发布包自身 DLL 和插件；Linux 使用包内 Qt / ICU 运行库，补齐 Wayland shell 插件后复测。

| 发布包场景 | 时长 | RSS 峰值 MB | 私有内存峰值 MB |
|---|---:|---:|---:|
| Windows，七种界面 / 配色 / 语言 | 60 秒 | 59.77 | 28.85 |
| Windows，69 次主题切换 / 70 次编辑 / 托盘 / 退出 | 65 秒 | 64.89 | 32.74 |
| Linux Wayland，72 次主题切换 / 72 次编辑 / 退出 | 65 秒 | 91.87 | 36.10 |

最终包全部低于 100 MB。Linux Wayland 压力场景的初始空闲段为单核 0.334% / 整机 0.021%；Windows 复测该段 CPU 增量低于系统计时分辨率，不能解释为任何情况下绝对不使用 CPU。长时间静置结果参考上表。Linux WSLg 没有托盘宿主时会记录 D-Bus ServiceUnknown，不影响窗口、编辑和退出。

## 功能验证

- Windows、Linux 均通过 CTest 的 core 和 gui 两组测试。共 15 项功能测试，Windows 通过 14 项并跳过 Linux PTY 测试，Linux 全部通过；另有 Qt Test 初始化 / 清理。覆盖 NRBF 解析、36 个官方主题渲染、JSON 迁移 / 保存、错误输入边界、图像尺寸上限、指标格式、嵌套分组和防循环、重命名 / 锁定 / 撤销 / 重做、复制、窗口缩放、偏好持久化及页面隔离。
- “微星”官方编辑示例的 480×320 图像与此前官方兼容渲染参考逐像素一致，差异像素数为 0；RGB565 包也一致。解组后背景、子图层坐标和绘制顺序保持一致。
- 协议覆盖 1000 组坐标头打包、方向 / 亮度固定字节、RGB565 字节序及变化矩形。Linux 额外使用 PTY 模拟 V2 串口，验证握手、初始化、完整帧、单像素差分、重复帧不发送及断开；Windows 跳过 PTY 测试。
- 原生窗口保存主题、编辑、传感器、设置、诊断、浅色和英文截图。托盘压力阶段在存在托盘服务时使用真正的窗口关闭流程；没有托盘宿主的桌面不隐藏到不存在的托盘。

## 尚未验证

没有将测试程序连接到真实副屏发送命令；设备驱动、固件握手时序、旋转 / 镜像的实机效果仍需硬件验证。Linux 预编译包来自当前 Arch 环境，不应视为所有发行版的通用二进制；其他系统可按 README 使用本地 Qt 从源码构建。
