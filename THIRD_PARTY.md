# Third-party materials

English | [简体中文](THIRD_PARTY.zh-CN.md)

- **Qt**: Windows uses Qt 6.8.0, and Linux prebuilt packages use Qt 6.11.1. The app dynamically links Core, Gui, Widgets, and Network, and uses platform, image, and TLS plugins distributed under the GPL v3 / LGPL v3 terms provided by Qt. The project itself is GPL-3.0-or-later. License copies are included in the release package's `licenses` directory; Qt is unmodified. Corresponding official source archives: [Qt 6.8.0](https://download.qt.io/archive/qt/6.8/6.8.0/single/) and [Qt 6.11.1](https://download.qt.io/archive/qt/6.11/6.11.1/single/).
- **libpulse**: Linux volume collection uses the native PulseAudio client library, which also works with PipeWire-Pulse. Licensed under LGPL-2.1-or-later; see [PulseAudio](https://www.freedesktop.org/wiki/Software/PulseAudio/).
- **UI color schemes**: `assets/ui-themes/*.json` adapts public color values from [Catppuccin](https://github.com/catppuccin/palette), [Dracula / Alucard](https://github.com/dracula/dracula-theme), [Nord](https://github.com/nordtheme/nord), [Solarized](https://github.com/altercation/solarized), and [Gruvbox](https://github.com/morhetz/gruvbox) to Qt roles. All upstream projects declare an MIT license (the Gruvbox README calls it MIT/X11). Original licenses and attribution notices are retained in `assets/ui-themes/licenses/`. Their editor and terminal theme implementations are not copied.
- **Open-Meteo**: Provides optional weather data and city search. Data is used under CC BY 4.0, with attribution links in the UI; see [Open-Meteo](https://open-meteo.com/). Approximate IP-based location comes from [ipwhois.io](https://ipwhois.io/), which is contacted only when weather is enabled and no city is specified.
- `assets/themes/official`: Themes from the user's local 35inchNEW software package, with background and status-bar images embedded in the theme files. Used for compatibility implementation and local validation; all original rights to these resources remain unchanged.
- `assets/fonts/GeForce_Bold.ttf`: Extracted from a byte-array resource in the same official application. Its font metadata reads “Generated in 2012 by FontLab Studio. Copyright info pending.” Derived glyph atlases and metrics come from GDI+ rendering at 72 DPI. Resource extraction does not execute the official application.
- `assets/fonts/Roboto_Regular_14.ttf`: A font embedded in the same application, with metadata crediting Google, 2011. Retained for reference; the current renderer does not load it.
- `assets/fonts/NotoSansSC.ttf`: A Google/Adobe Noto Sans SC Regular instance, licensed under the SIL Open Font License 1.1. The original license is in `assets/fonts/OFL.txt`.
- `assets/fonts/TuringScreenSans.ttf`: A renamed subset of Noto containing common Simplified Chinese characters, characters used by the UI, and Latin characters. It remains under SIL OFL 1.1. The generation script, `scripts/generate-font.py`, requires fontTools only at build time; the application does not depend on Python.
- `assets/fonts/TuringScreenSymbols.ttf`: An approximately 8 KB Unicode icon font containing hardware, network, system, and weather icons, subsetted and renamed from [JetBrainsMono Nerd Font 3.5.0](https://github.com/ryanoasis/nerd-fonts). Font tables and the space glyph retain the JetBrains Mono and Nerd Fonts SIL OFL 1.1 licensing. Icon outlines come from [Material Design Icons / Pictogrammers](https://github.com/Templarian/MaterialDesign-Webfont), licensed under Apache-2.0. Licenses and attribution are in `TuringScreenSymbols-OFL.txt`, `MaterialDesign-APACHE-2.0.txt`, and `TuringScreenSymbols-NOTICE.txt`. The generation script is `scripts/generate-symbol-font.py`.
- The NixOS icon glyph comes from [Font Logos](https://github.com/lukas-w/font-logos), under the Unlicense. The license text is retained in `assets/fonts/FontLogos-UNLICENSE.txt`.
- `assets/fonts/TuringScreenLatin-Regular.ttf` / `TuringScreenLatin-SemiBold.ttf`: Latin subsets of Inter 4.1 used by Nightfall, renamed to Turing Screen Latin and retaining SIL OFL 1.1. The license is in `TuringScreenLatin-OFL.txt`. Upstream project: [Inter](https://github.com/rsms/inter). Generation script: `scripts/generate-latin-font.py`.
- `assets/fonts/TuringScreenMono.ttf`: A JetBrains Mono 2.304 Bold ASCII subset used by the clock, generated from JetBrainsMono Nerd Font 3.5.0 and renamed to Turing Screen Mono. Licensed under SIL OFL 1.1, with the license in `TuringScreenMono-OFL.txt`. Generation script: `scripts/generate-mono-font.py`.
- The Microsoft Visual C++ runtime in Windows packages comes from the local MSVC 2022 redistributable runtime directory and remains subject to Microsoft's original terms.
- Qt, ICU, double-conversion, and other runtime libraries in Linux packages retain the licenses from the build system, included in `licenses`.

NRBF parsing, the theme model, data collection, rendering, and serial communication are implemented in C++ within this project. There is no Rust, Python, or WebEngine runtime dependency. On Windows, the app can optionally read data from the user's running HWiNFO, AIDA64, or LibreHardwareMonitor instance. It does not distribute their software or drivers, or launch a separate sensor helper process.

- The HWiNFO shared-memory layout references the [HWiNFO Shared Memory Interface](https://www.hwinfo.com/forum/forums/shared-memory-interface.13/). HWiNFO is licensed separately by its rights holders. See the [official licensing information](https://www.hwinfo.com/licenses/) for the free edition's limit on continuous shared-memory use.
- The AIDA64 shared-memory implementation references its [public interface documentation](https://www.aida64.com/user-manual/hardware-monitoring/external-applications?language_content_entity=en). AIDA64 is licensed separately by FinalWire.
- The local LibreHardwareMonitor web interface references its [HttpServer implementation](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/blob/master/LibreHardwareMonitor.Windows.Forms/Utilities/HttpServer.cs). This project implements only a JSON API client and does not copy or bundle its libraries. The upstream project uses MPL-2.0.
